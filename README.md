## `/about`

I study how systems behave when assumptions fail.

My work focuses on understanding attack surfaces, identifying weak trust boundaries, reproducing vulnerabilities and building controlled environments for security research.

Most of the material published here comes from:

- purpose-built security labs
- CTF environments
- systems I own
- authorized testing environments
- technical experiments and research

The objective is not simply exploitation.

It is understanding **why something breaks**, **how it can be reproduced**, and **how the underlying system behaves**.
