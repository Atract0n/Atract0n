## `// PHILOSOPHY`

Security is rarely about a single failure.

Complex systems are built from interactions.

Interactions create unexpected states.

Unexpected states create attack surfaces.

```text
INPUT
  │
  ├───────────────┐
  ↓               ↓
SYSTEM ───────→ SYSTEM
  │               │
  ↓               ↓
STATE           STATE
  │               │
  └───────┬───────┘
          ↓
      BEHAVIOR
          ↓
       FAILURE?
```

Understanding the failure requires understanding the system.
